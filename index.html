What it does

Nine parts of it.

Play

  • A player built around your keyboard
  • 15 shortcuts, all rebindable
  • Frame-by-frame stepping
  • 0.1× to 16×, hold to boost
  • Picks up where you stopped
  • Cinema mode, controls that get out of the way
  • MP4, MKV, AVI, MOV, WebM, MP3 and more

Library

  • Point it at as many folders as you like
  • Grouped by folder, playlist and channel
  • Thumbnail grid, generated for you
  • Trash, with a live count
  • Reveal any file in Explorer

Find

  • Searches your library, best match first
  • A shortcut to search YouTube instead

Download

  • Paste a link, get the file
  • Simple — best quality, merged automatically
  • Advanced — pick every stream yourself
  • Direct — choose quality and audio language
  • Playlist — grab a whole playlist at once
  • 144p all the way to 8K
  • Pause and resume, even after you close the app

Follow

  • Track channels, auto-download new uploads
  • New videos queue up behind a badge
  • You pick the quality

Save

  • Bookmark links with thumbnails
  • Categories, plus export and import

Ambience

  • Layer looping background sounds
  • Volume and seek on each one

Private shelf

  • A password-locked folder that locks itself when time runs out

Built in

  • A browser, without leaving the app
  • Play any file from the Windows right-click menu
  • A second window for floating playback
  • An update button when a new version ships

What changed in version 3

The download queue was rebuilt. Everything else carried forward.

v3.0.1 Latest 13 Oct
  • The download page moved to a new host, so the update button inside the app points at the new address.
  • Everything else is identical to 3.0.0.
Download v3.0.1
v3.0.0 13 Oct
  • Cancel, pause and resume now work. They used to report success even when nothing happened, so a stuck download looked exactly like a working one.
  • A download you are busy with cannot be overwritten by a stale update mid-click.
  • Cancelling one download no longer deletes another’s partial files.
  • Deleting only ever removes files inside your library folders.
  • The header is now two buttons, and the update prompt only appears when there is genuinely an update.
